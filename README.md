# Wonderful Nuts — Make Happy Everyday

Premium dry fruits, nuts, berries, seeds, and royal festive gift hampers e-commerce web application.

## Overview
- **Royal Whole Nuts & Catalog Showcase**: Complete categorized catalog featuring Jumbo Cashews, California Almonds, Pistachios, Kashmiri Walnuts, Turkish Hazelnuts, Himalayan Chilgoza Pine Nuts, Mammoth Pecans, Arabian Medjool Dates, and Royal Spices.
- **Dynamic Pack Size Selector**: Real-time multi-weight switcher (100g, 200g, 250g, 500g, 1kg) with instant pricing and savings updates.
- **Interactive Slide-Over Cart & Wishlist**: Real-time item management, free shipping progress tracker, coupon codes, and order calculation.
- **Customer Favorites & Trending Carousel**: Smooth horizontal scrollable carousel with uniform card alignment and quick actions.
- **Wellness & Nutrition FAQs**: Accordion answering daily portion recommendations, weight management, and skin/hair benefits.
- **Ultra-Fast Performance**: 100% local typography, WebP-optimized imagery, glassmorphism hero navigation, and responsive CSS for mobile and desktop.

## Running Locally
Start a local static server:
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.
